## 📈 `09 // COMPLEXITY RADAR`

I don't stop at **Accepted**.

I also ask:

```text
                 ┌──────────────┐
                 │   ACCEPTED   │
                 └──────┬───────┘
                        ↓
               ┌─────────────────┐
               │   HOW FAST?     │
               └────────┬────────┘
                        ↓
               ┌─────────────────┐
               │   HOW MUCH      │
               │     MEMORY?     │
               └────────┬────────┘
                        ↓
               ┌─────────────────┐
               │   CAN IT BE     │
               │   OPTIMIZED?    │
               └─────────────────┘
```

### Complexity targets

`O(1)` → `O(log n)` → `O(n)` → `O(n log n)` → `O(n²)`

The target isn't always the smallest Big-O on paper — it's understanding the **trade-off**.
